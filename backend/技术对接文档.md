# 额尔齐斯河流域水资源预报管理系统 — 技术对接文档

## 一、系统定位

本系统为额尔齐斯河流域上游水资源预报管理提供可视化平台，核心能力包括：多站点气象-水文观测数据接入与管理、水文模型预报运行与结果展示、人工数据补录与审核。系统采用前后端分离架构，对外以 RESTful API 形式提供数据服务，支持第三方系统跳转对接与数据集成。

---

## 二、技术架构

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| 前端 | Vue 2.7 + Element UI + ECharts + Leaflet | 单页应用，独立部署 |
| 后端 | Django 5.1 + DRF 3.17 | RESTful API 服务 |
| 数据库 | PostgreSQL + TimescaleDB | 时序数据扩展，端口 15432 |
| 任务调度 | APScheduler（过渡）→ Celery + Redis | 异步任务队列（规划中）|
| 网关 | Nginx（生产）/ Django 开发服务器 | 反向代理与静态资源分发 |

---

## 三、对接地址

| 环境 | 地址 |
|------|------|
| 前端页面 | `http://<host>:<port>/`（Vue 独立部署） |
| API 基地址 | `http://<host>:<port>/api/` |
| API 文档 | `http://<host>:<port>/api/schema/`（OpenAPI 3.0） |
| 管理后台 | `http://<host>:<port>/admin/`（Django Admin） |

> 注：当前开发环境已配置 `CORS_ALLOW_ALL_ORIGINS = True`，跨域请求可直接访问。

## 四、核心 API 端点

| 端点 | 方法 | 说明 | 权限 |
|------|------|------|------|
| `/api/stations/` | GET | 站点列表 | 公开 |
| `/api/weatherdata/` | GET | 气象观测数据（支持时间过滤） | 公开 |
| `/api/weather-daily-agg/` | GET | 日级聚合数据（预计算） | 公开 |
| `/api/weather-hourly-agg/` | GET | 小时级聚合数据（预计算） | 公开 |
| `/api/hydrology-forecast-daily/` | GET | 水文日预报结果 | 公开 |
| `/api/hydrology-runs/` | GET / POST | 预报运行记录 / 手动触发 | 需认证 / 管理员 |
| `/api/manual-data/` | POST | 人工数据录入 | 需认证 |
| `/api/tiles/<dataset>/<z>/<x>/<y>.png` | GET | 地图瓦片服务 | 公开 |

### 常用过滤参数示例

```
# 按站点名过滤
GET /api/weatherdata/?station__name=HXC

# 按时间范围过滤
GET /api/weatherdata/?timestamp__gte=2026-01-01T00:00:00Z&timestamp__lte=2026-01-31T23:59:59Z

# 日聚合数据按日期范围
GET /api/weather-daily-agg/?station__name=HXC&day__gte=2026-01-01&day__lte=2026-01-31
```

> 未传时间参数时，`/api/weatherdata/` 默认返回最近 7 天数据。

## 五、认证方式

当前阶段采用 **Session + Basic Auth** 双模式：

| 方式 | 使用场景 | 请求头 |
|------|----------|--------|
| Session | 浏览器内同源访问 | 自动携带 Cookie |
| Basic Auth | 第三方系统 / 脚本对接 | `Authorization: Basic <base64(user:pass)>` |

> 后续将升级为 JWT Token 认证（Access Token 2h + Refresh Token 7d），届时将提供 `/api/token/` 与 `/api/token/refresh/` 端点。

## 六、数据格式

### 响应格式
统一返回 JSON，结构如下：

```json
{
  "count": 100,
  "next": "http://host/api/weatherdata/?page=2",
  "previous": null,
  "results": [...]
}
```

> 注：天气数据、聚合数据等接口已取消分页（`pagination_class = None`），按过滤条件返回全部匹配数据。

### 时间格式
- 请求参数：ISO 8601（`2026-01-01T00:00:00Z`）
- 响应字段：`YYYY-MM-DDTHH:MM:SSZ`

### 关键数据实体

| 实体 | 核心字段 |
|------|----------|
| Station | `id`, `name` |
| WeatherData | `station`, `timestamp`, `ws`, `wd`, `ta`, `rh`, `pressure`, `rainsnow`, `snow_depth`, `vwc_soil_10cm` ~ `100cm`, `t_soil_10cm` ~ `100cm` 等 |
| HydrologyForecastDaily | `station`, `target_date`, `flow_avg`, `model_name`, `model_version` |

## 七、跨域与嵌入

- **CORS**：当前已开放全部来源（`CORS_ALLOW_ALL_ORIGINS = True`），支持 iframe 嵌入与跨域 AJAX 调用。
- **网页跳转**：前端为独立 Vue SPA，可通过标准 URL 路由跳转至指定页面（如 `/station/HXC`、`/forecast` 等，具体路由以实际部署为准）。
- **iframe 嵌入**：如需将本系统页面嵌入第三方门户，直接引用前端地址即可，无额外跨域限制。
